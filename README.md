# 🚦 SUMO + Mapbox Smart Traffic Simulation

## 📌 Project Overview

This project integrates SUMO Traffic Simulator with Mapbox GIS visualization to simulate and analyze urban traffic movement in Kathmandu, Nepal.

The system provides real-time vehicle movement visualization, traffic congestion monitoring, and adaptive traffic signal optimization using GIS and transportation analysis techniques.

---

# 🌍 Objectives

- Simulate real-world traffic movement
- Analyze congestion patterns
- Visualize vehicle movement on interactive maps
- Explore smart mobility systems
- Study transportation optimization methods
